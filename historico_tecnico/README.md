# Linha do Tempo Técnica — Pyton Knight

> Histórico reconstruído em 18/09/2026 a partir dos snapshots reais preservados pelo grupo.  
> Os commits desta branch documentam versões anteriores do projeto, mas **não fingem datas antigas de Git**. A branch `main` permanece como fonte da versão atual.

## Objetivo

Esta branch registra a evolução técnica do Pyton Knight para fins de rastreabilidade do TCC, permitindo demonstrar como o projeto passou de um protótipo inspirado em CodeCombat até a versão atual em Phaser.

## Como ler este histórico

Cada marco recuperado possui uma pasta própria com:

- descrição do estado do projeto;
- origem do snapshot;
- integridade do arquivo original;
- arquivos-fonte representativos, quando aplicável;
- relação com o marco seguinte;
- observação explícita de que se trata de histórico recuperado.

Os snapshots completos continuam preservados fora desta branch. O objetivo aqui é manter uma linha do tempo técnica legível, e não duplicar dezenas de megabytes de arquivos compactados no repositório.

## Regra de preservação

A branch `main` não deve ser reescrita para encaixar artificialmente versões antigas antes da V3/V4. O histórico recuperado permanece separado justamente para preservar os commits reais já existentes e, ao mesmo tempo, documentar a trajetória anterior do TCC.
