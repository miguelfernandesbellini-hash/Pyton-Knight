## Estado do projeto

Este é o marco anterior à adoção do Phaser. O protótipo funciona diretamente no navegador e já demonstra a ideia central do TCC: escrever comandos em um ambiente inspirado em CodeCombat para controlar Guto.

Segundo o próprio `LEIA-ME.txt` preservado no snapshot, o objetivo didático era:

- criar uma variável numérica;
- reutilizar o valor armazenado em uma ação;
- produzir feedback visual imediato a partir do código escrito.

A solução de referência do protótipo utilizava uma variável `passos` e comandos específicos de movimento. O protótipo interpretava apenas comandos permitidos pela atividade, sem executar Python arbitrário.

## Importância para o TCC

Este marco registra a **prova de conceito da interação pedagógica** antes da arquitetura do jogo ser transferida para Phaser.
